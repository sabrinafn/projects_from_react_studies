# projects_from_react_studies

This repository is a collection of projects built while studying React.


## Repository structure

```text
investment-calculator/  Investment growth calculator
tic-tac-toe/            Two-player Tic-Tac-Toe game
```

## Investment Calculator

Calculates investment growth over time based on the initial investment, annual contributions, expected return, and investment duration.

### How to run

The project uses Node.js and npm. From the repository root, start the app with:

```bash
cd investment-calculator
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.
